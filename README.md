--- IMPORTANT ---
1. OCP is required and a roster hack is recommended.
2. This mod is compatible with Outsider's EXG mod but it's not recommended. The EXG compatible version will have overall less stability and unlocks compared to the standard version of the mod.
3. If you don't want your characters locked but still want to unlock achievements, use the unlock all characters cheat code.
4. It is required to have Captain America, Thor, Spider-Man, and Wolverine in your roster or else this mod will crash.

--- HOW TO INSTALL ---
1. Extract the Improved Unlockables file wherever you like.
2. Open the Reset all unlocks file, then open the Achievement sound picker file if you want to change achievement sounds.
3. Copy the folders named data, dialogs, scripts, and sounds. Paste those folders into your Ultimate Alliance 1 directory. (where your game.exe is at)
4. Replace all files, start the game.

--- MOD ORGANIZER 2 INSTALL METHOD ---
1. Open the Reset all unlocks file, then open the Achievement sound picker file if you want to change achievement sounds.
2. Open the Mod Organizer 2 Version folder and Install the Improved-Unlockables.rar file into MO2.
